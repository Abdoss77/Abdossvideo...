Pourquoi vous n'arrivez pas à copier

Il y a 3 causes possibles :

1. Le code est trop long
Vos fichiers font 1500 à 2500 lignes chacun. Les téléphones ont du mal à sélectionner et copier de gros blocs de texte d'un coup. La sélection s'arrête toute seule, ou le bouton « Copier » ne réagit pas.

2. Le navigateur mobile limite la sélection
Dans une conversation de chat comme celle-ci, le navigateur ne permet pas toujours de « tout sélectionner ». Il faut faire défiler et sélectionner manuellement, ce qui est presque impossible sur 2000 lignes.

3. Le code contient des caractères spéciaux
Les chevrons <>, les accolades {} et les guillemets peuvent perturber la sélection sur certains navigateurs.
